# 产品需求文档 — 法定节假日禁止用券

## 1. 需求背景

### 业务背景
慧停车业主方平台的优惠券发行管理中，运营人员需要对停车优惠券（面额券、时长券、折扣券、单次免单券）设置不可用时段限制，以避免在法定节假日或特定时段被不合理使用。

### 问题描述
当前优惠券规则仅支持"欠费订单限制"，无法限制优惠券在法定节假日或特定自定义时段的使用，导致运营灵活性不足。

### 影响范围
- 前端 Web 管理平台（业主方）
- 涉及模块：发行管理、使用管理
- 后端接口已开发（RAP2 接口ID 3491、3493）

--- 

## 2. 目标与范围

### 核心目标
在停车优惠券规则中新增"不可用时段限制"配置项，支持法定节假日不可用和自定义时段不可用两种模式。

### 成功标准
- 运营人员可在新建优惠券规则时配置不可用时段限制
- 详情页可正确展示不可用时段限制信息
- 非停车券类型不显示该配置项

### 范围边界
- **前端范围内**：发行管理新建规则弹窗、发行管理详情页、使用管理详情页
- **前端范围外**：车主小程序/APP 展示（后端处理）、后端接口逻辑
- **不涉及**：编辑回显（发行管理不支持编辑）

---

## 3. 功能需求

### 功能点1：新建规则弹窗 - 不可用时段限制表单

**用户故事**：作为运营人员，我希望在新建停车优惠券规则时，能够配置"不可用时段限制"，使优惠券在法定节假日或自定义时段不可使用。

**显示条件**：
- 券类型为停车券（`couponType === '1'`）
- 且规则类型为面额(1)/时长(3)/折扣(2)/单次免单(6)
- 条件表达式：`basicInfo.type === '1' && ['1','2','3','6'].includes(ruleType)`

**表单位置**：欠费订单限制后面、优惠券名称前面

**交互说明**：

#### 3.1.1 法定节假日不可用
- 展示全选 Checkbox + 7 个单选 Checkbox
- 全选 Checkbox 文案："法定节假日不可用"
- 7 个节假日选项：元旦、春节、清明节、劳动节、端午节、中秋节、国庆节
- 全选联动：全选 → 全部勾选，取消全选 → 全部取消，部分选 → 半选态（indeterminate）
- Checkbox value 使用中文名称
- 非必填，默认不勾选

#### 3.1.2 自定义时段不可用
- 展示 Checkbox "自定义时段不可用"
- 勾选后显示时段列表区域
- 每行包含：开始时间选择器 ~ 结束时间选择器 + 删除链接
- 时间格式：`yyyy-MM-dd HH:mm`
- 底部"添加时段"按钮，最多 5 条，满 5 条隐藏按钮
- 每条时段需同时填写开始和结束时间
- 非必填，默认不勾选

#### 3.1.3 数据提交
- `unavailableHolidays`：String，选中的节假日中文名称用顿号（、）隔开，如 `"春节、清明节"`；未选择时为空字符串
- `unavailableCustomPeriods`：Array，每项 `{startTime: string, endTime: string}`；未勾选自定义时段时为空数组
- 两个字段在 `detailInfo` 嵌套参数内提交

#### 3.1.4 规则列表表格
- 新增列"不可用时段限制"，`dataIndex: 'unavailablePeriodInfo'`
- 超长文本使用 ellipsis + tooltip 悬停查看
- 位于"欠费订单限制"列后面

#### 3.1.5 重置逻辑
- 关闭弹窗/取消时，清空所有不可用时段限制状态

### 功能点2：发行管理详情页 - 不可用时段限制展示列

**用户故事**：作为运营人员，我希望在查看发行管理详情时，能看到优惠券规则的不可用时段限制信息。

**交互说明**：
- 在优惠券规则表格中新增"不可用时段限制"列
- 字段：`unavailablePeriodInfo`（后端已拼接好的展示文本）
- 列位置："欠费订单限制"列后面
- 超长文本使用 ellipsis + tooltip
- 仅在 columns 表格中新增，不涉及 Profile 模式

### 功能点3：使用管理详情页 - 不可用时段展示

**用户故事**：作为运营人员，我希望在使用管理详情页查看优惠券信息时，能看到不可用时段限制。

**交互说明**：
- 在优惠券信息 Profile 区域新增"不可用时段限制"字段
- 字段：`unavailablePeriodInfo`（后端已拼接好的展示文本）
- 字段位置："多券叠加使用"后面
- 使用 `ifShow` 判断，无数据时不显示该行（避免空行）

## 4. 非功能需求

### 性能要求
- 无特殊性能要求，7 个 Checkbox 和最多 5 行自定义时段对渲染无压力

### 兼容性要求
- 遵循现有 UI 框架（@sonli-design/sun-ui）
- 时间选择器使用 sun-ui DatePicker 组件
- Checkbox/CheckboxGroup 使用 sun-ui 组件

### 可用性要求
- 法定节假日全选联动需流畅，半选态正确显示
- 自定义时段添加/删除交互直观
- 时间选择器格式统一为 `yyyy-MM-dd HH:mm`

## 7. 术语定义

| 术语 | 说明 |
|------|------|
| 不可用时段限制 | 优惠券规则中新增的配置项，限制优惠券在特定时段不可使用 |
| 法定节假日不可用 | 勾选后，优惠券在选中的法定节假日不可使用 |
| 自定义时段不可用 | 勾选后，优惠券在指定的自定义时段不可使用 |
| unavailableHolidays | 入参字段，节假日中文名称顿号隔开 |
| unavailableCustomPeriods | 入参字段，自定义时段数组 |
| unavailablePeriodInfo | 返参字段，后端拼接的展示文本 |
| ruleType | 优惠券规则类型：1面额 2折扣 3时长 4免费停车 5定额支付 6单次免单 |
| couponType | 券类型：1停车券 3充电券 4长租券 5商品券 |
