# Spec-Kit 文档仓库

## 概述
这是松立研发团队的AI开发规范文档仓库，用于管理产品需求文档、功能设计文档、测试用例和项目进度报告。

## 目录结构
```
产品中心月度计划/
├── pm/prd/              # 产品需求文档
├── dev/                 # 功能设计文档
│   ├── plans/          # 需求拆解
│   ├── tasks/          # 任务分配
│   ├── test report/    # 测试验收报告
│   └── review report/  # 代码审查报告
└── test/               # 测试文档
    ├── testcases/      # 测试用例
    └── test report/    # 测试验收报告
```

## 使用说明
1. 使用 `/document` 技能生成和管理文档
2. 文档模板位于各目录的 `_template.md` 文件中
3. 项目概览更新在根目录的 `overview.md`

## 维护指南
- 每日更新 `overview.md` 项目进度
- 文档需经过评审后才能合并
- 使用标准模板确保文档一致性
